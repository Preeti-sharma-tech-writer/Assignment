Android DMA consent guide

Overview

Under the EU Digital Markets Act, companies designated as gatekeepers by the European Commission, including Google, may not use European users’ personal data obtained from third-party services for activities such as advertising without user consent.

For users subject to GDPR, Google requires their consent choices for advertising data usage and personalized advertising. For users who are not subject to GDPR, the SDK API does not require additional consent parameters. The SDK does not store the consent data. Store the relevant consent information in your app and set it in the SDK before every call to start().

Manually collect consent data

Apps using a CMP

If your app uses a TCF v2.2-compatible CMP, call enableTCFDataCollection(true) after you initialize the SDK. Start the SDK after the CMP indicates that the user made a consent decision. The SDK reads the TCF strings from SharedPreferences and sends the consent data with every server request.

The manual steps below are for apps that don't use a compatible CMP.

Follow these steps to complete the setup:

  1. Use AppsFlyer SDK v6.13.0 or later.
  2. Implement a Deferred Start flow so that the AppsFlyer SDK does not start before the user’s consent decision is available.
  3. Determine whether GDPR applies to the user.
    4. If GDPR applies:

    Call AppsFlyerConsent.forGDPRUser() with both consent values to create the consent object:

    1. hasConsentForDataUsage
    2. hasConsentForAdsPersonalization
    Java Kotlin
    Java
    // 
boolean hasConsentForDataUsage = true;
boolean hasConsentForAdsPersonalization = true;

AppsFlyerConsent gdprUserConsent = AppsFlyerConsent.forGDPRUser(
    hasConsentForDataUsage,
    hasConsentForAdsPersonalization
);
AppsFlyerLib.getInstance().setConsentData(gdprUserConsent);
    Kotlin
    
val gdprUserConsent = AppsFlyerConsent.forGDPRUser(
    hasConsentForDataUsage = true,
    hasConsentForAdsPersonalization = true
)
AppsFlyerLib.getInstance().setConsentData(gdprUserConsent)
    If GDPR doesn't apply:

    Call AppsFlyerConsent.forNonGDPRUser() to create the consent object.

    Java Kotlin
    Java
    
AppsFlyerConsent nonGdprUser = AppsFlyerConsent.forNonGDPRUser();
AppsFlyerLib.getInstance().setConsentData(nonGdprUser);
    Kotlin
    
val nonGdprUser = AppsFlyerConsent.forNonGDPRUser()
AppsFlyerLib.getInstance().setConsentData(nonGdprUser)
  4. Pass the consent object to setConsentData(). Your app must store the relevant consent values and set the consent data in the SDK before every call to start().
  5. Call start().
